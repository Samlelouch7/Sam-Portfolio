# Sam Parmar — Creative Portfolio

> **Material 3 Expressive Portfolio** showcasing 2D Animation, 3D Motion & Modeling, Woodcraft, Pencil & Digital Artworks, and YouTube channel releases.

[![Deploy Portfolio to GitHub Pages](https://github.com/Samlelouch7/Sam-Portfolio/actions/workflows/deploy.yml/badge.svg)](https://github.com/Samlelouch7/Sam-Portfolio/actions/workflows/deploy.yml)

---

## 🎨 Overview

This portfolio is an editorial, responsive, high-performance web experience built with **Google Material Design 3 (M3) Expressive**:
- **2D Animation**: Classical hand-drawn and FX animations (*Bow and Arrow*, *Fire 2D*, *Heavy Lift*, *Personality Walk*).
- **3D Animation & Modeling**: 3D character motion, Blender scenes, sci-fi environment renders, and character dialogue (*Dialoge Emily* with AAC audio).
- **Woodcraft**: Handcrafted functional and decorative woodwork.
- **Pencil & Digital**: 31 curated drawings, master studies, character designs, and sketches (including Jono Dry inspired studies).
- **YouTube Channel**: 20 video releases & shorts pulled directly from [@samparmar1522](https://www.youtube.com/@samparmar1522).

---

## ⚡ Features

- **Persistent Floating Sections Tab Dock**: Always visible while scrolling, with a smooth sliding active indicator pill and spring transitions.
- **Material 3 Expressive System**: Dynamic nightfall/obsidian surface containers, radiant periwinkle primary accents, and organic 28px rounded geometry.
- **Interactive Lightbox Modal**: Fullscreen view with video controls, responsive YouTube iframe player, and keyboard shortcuts (`[←]`, `[→]`, `[Esc]`).
- **Zero Cost & Self-Contained**: 100% static HTML, CSS, and Vanilla JavaScript with cached local thumbnails. No build steps, no package managers, and zero dependencies.

### To Enable GitHub Pages:
1. In this repository, go to **Settings** → **Pages**.
2. Under **Build and deployment > Source**, select **GitHub Actions**.
3. The `.github/workflows/deploy.yml` workflow will automatically deploy your portfolio!
